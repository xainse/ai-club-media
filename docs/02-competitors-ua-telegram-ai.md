## 8. Чекліст наступного маркетингового дослідження

Для кожного **Must/Should** каналу зібрати:

1. **Контент-мікс** (новини / кейси / особисте / продаж курсу) — 20 останніх постів  
2. **Частота** і формат (текст / відео / карусель / дайджест)  
3. **Тон** (CEO / освітянин / мем / інженер)  
4. **CTA і монетизація** (реклама, курс, агенція, комʼюніті)  
5. **ER-проксі:** views / forwards / reactions на 5 типових постів  
6. **Оцінка ICP overlap** з ціллю AI Club (1–5)  
7. **Можливість крос-промо / колаборації** (так / ні / пізніше)  
8. **TGStat / Telemetr** (після ручного підтвердження handle): ER, прирост, рекламні згадки
